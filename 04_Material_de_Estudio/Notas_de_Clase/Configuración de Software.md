Actividades Fundamentales de la SCM
1. Identifica ítems de Configuración
	1. Definir una regla de nombrado (Nombre, regla, ubicación)
	2. Crear un Glosario
	3. Crear un Plan de SCM
2. Control de cambios (Llegar a una Línea Base o Configuración Estable)
	1. La configuración es una "foto" del estado actual de la configuración, las Líneas Base suelen estar ligadas a "hitos"
3. Reporte de Estados
4. Auditorías de Configuración(Proceso de evaluación que busca ser objetivo, por ende, debe ser externo)
	* Tener previamente preparada una checklist; que es la herramienta para realizar una auditoría, para poder tener una referencia de los estados exitosos del proceso/proyecto/configuración a auditar
	1. Física
		* Confirmar que los IC estén y respeten el Plan de Configuración
	2. Funcional (Matriz de rastreabilidad o Trazabilidad)
		* Asegura la integridad, Valida la trazabilidad con la ERS (por mencionar un documento)
